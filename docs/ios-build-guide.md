# iOS Build & Release Guide

Utah City Host Capture — iOS app built with Capacitor.

## Architecture

The iOS app is a Capacitor native shell that loads the production Utah City web app
(`https://www.utahcity.app`) inside a WKWebView. The app adds native iOS capabilities:

- **Microphone permission** (`NSMicrophoneUsageDescription`) for voice recording
- **Native status bar** styling to match the dark UI theme
- **Splash screen** while the web app loads
- **Safe area insets** for iPhone notch / Dynamic Island / home indicator
- **Portrait lock** on iPhone (landscape allowed on iPad)

All authentication, transcription, AI extraction, and data storage use the existing
production backend — zero backend changes required.

## Local Development (Windows)

You can generate and sync the iOS project on Windows, but you cannot compile it locally.

```bash
# Install dependencies
npm install

# Sync Capacitor iOS project (copies web assets + updates plugins)
npx cap sync ios
```

The `ios/` directory contains the full Xcode project. It's generated by Capacitor and
committed to the repo so CI/CD can build it without running `cap add ios`.

## CI/CD Pipeline (GitHub Actions)

The app is built and deployed automatically via `.github/workflows/deploy-ios.yml`:

1. **Trigger**: Push to `main` (or manual dispatch)
2. **Runner**: `macos-14` (Apple Silicon M1/M2, free tier: 200 min/month)
3. **Steps**:
   - `npm ci` → `npx cap sync ios`
   - `pod install` (CocoaPods)
   - Fastlane `match` (auto-manage certificates & provisioning profiles)
   - `xcodebuild` → `.ipa`
   - Upload to TestFlight

### Required GitHub Secrets

Set these in your repo's Settings → Secrets → Actions:

| Secret | Description |
|---|---|
| `APP_STORE_CONNECT_KEY_ID` | Key ID from App Store Connect → Integrations → API Keys |
| `APP_STORE_CONNECT_ISSUER_ID` | Issuer ID from the same page |
| `APP_STORE_CONNECT_PRIVATE_KEY` | Base64-encoded `.p8` private key file |
| `MATCH_PASSWORD` | Passphrase for encrypted certificate repo |
| `MATCH_GIT_BASIC_AUTHORIZATION` | Base64-encoded `username:token` for the match cert repo |

### Generating the API Key

1. Go to [App Store Connect → Users and Access → Integrations → App Store Connect API](https://appstoreconnect.apple.com/access/integrations/api)
2. Click **Generate API Key**
3. Give it **Admin** or **App Manager** role
4. Download the `.p8` file (only available once!)
5. Record the **Key ID** and **Issuer ID** shown on the page
6. Base64-encode the `.p8` file:
   ```bash
   base64 -i AuthKey_XXXXXXXXXX.p8 | tr -d '\n'
   ```
7. Set the base64 string as `APP_STORE_CONNECT_PRIVATE_KEY` in GitHub Secrets

## Distribution: Apple Business Manager (Custom App)

This app is distributed as a **Custom App** via Apple Business Manager (ABM), not the
public App Store. This means:

- The app is invisible in App Store search
- Hosts install via one-tap redemption code links
- No MDM enrollment required on personal iPhones
- App updates push automatically via the App Store update mechanism

### ABM Setup Steps

1. **Get a D-U-N-S number**: Free from [Dun & Bradstreet](https://www.dnb.com/duns.html) (1–5 business days)
2. **Register at [business.apple.com](https://business.apple.com)** using the D-U-N-S number
3. **In App Store Connect**: Set the app's distribution to Custom App, enter your ABM Org ID
4. **In ABM**: Navigate to Custom Apps → select the app → Redemption Codes → request licenses
5. **Email each host** their unique redemption link

### Fallback: Unlisted App Distribution

If ABM verification is slow, apply for [Unlisted App Distribution](https://developer.apple.com/contact/request/unlisted-app-distribution/).
This gives a direct App Store URL that works but is hidden from search.

## App Store Submission Checklist

Before first submission, prepare:

- [ ] **App icon**: 1024×1024 PNG (no transparency, no rounded corners)
- [ ] **Screenshots**: iPhone 15 Pro Max (1290×2796) — login screen + capture screen
- [ ] **Privacy policy URL**: Required by Apple
- [ ] **Support URL**: Required by Apple
- [ ] **Microphone usage description**: Already configured in Info.plist
- [ ] **Review credentials**: Provide a test host email/password in App Review Notes
- [ ] **Bundle ID**: Confirmed as `com.utahcity.host` in capacitor.config.ts
